# Clock Project

This project was originally created just for fun. It’s a simple clock application built to experiment with web development and try out different ideas. There was no intention for it to be amazing or groundbreaking — it’s simply a personal project to explore and learn.

Feel free to explore the code and see how it works. The design and features are basic, and everything was built with enjoyment in mind rather than perfection. I wrote this code about eight months ago. It’s definitely not the best code I can produce, but it shows how far I’ve come since then.
